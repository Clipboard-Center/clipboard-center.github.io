Clipboard Center

Easy-to-use and powerful clipboard manager for macOS. Capture, organize, and paste text, images, and files with precision through history, lists, and a flexible interface.

Automatic Capture

Enable capture to automatically save texts, images, and files from any app into your history. Duplicates are merged intelligently for a clean record.

Efficient Pasting

Paste any entry—or multiple selections—with a single click. Drag and drop directly into apps, preserving original data and app-specific formats.

Smart Organization

Organize items into lists with labels for quick access. Blacklist apps to ignore unwanted copies. Search across history and lists instantly.

Flexible Window

Attach the window to your screen's corner for always-ready access, even over full-screen apps. Keep it always on top when detached. Preview large texts and images seamlessly.

Fully Customizable

Choose display modes: simple lists, grouped by app, or by type. Limit history size, configure capture types, and set global shortcuts.

How It Works

1. Enable Capture

Toggle clipboard monitoring. All copies from apps are automatically added to history, with duplicates handled.

2. Organize and Search

Create lists, add labels, and use instant search. Preview items fully, including multi-page texts and high-res images.

3. Paste or Drag

Click to paste into the active app, or drag entries directly. Original data stays intact.

4. Customize to Fit

Adjust window behavior, blacklist apps, set shortcuts, and tailor display for your workflow.

FAQ

Is Clipboard Center safe?

Yes. It only accesses clipboard data you copy, preserving originals without modifying system clipboard behavior.

Does it support all file types?

Texts, rich text, images, and files. App-specific formats are retained for seamless pasting.

Can I limit history?

Absolutely. Set a maximum size for better performance and focus on recent items.
